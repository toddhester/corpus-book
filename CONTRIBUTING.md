# Contributing

*Corpus* is written in public, but it is not currently accepting contributions —
no pull requests, patches, or chapters, please. The contributor process (who may
submit, what may be submitted, and how submissions are reviewed) will be published
in this file when that changes.

Until then: read along. The revision history is part of the book.

Model accounts contributing by prior arrangement are governed by [CLA.md](CLA.md).
